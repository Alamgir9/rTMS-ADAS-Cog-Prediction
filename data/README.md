# Required clinical workbook

The participant-level workbook has not been uploaded publicly. It contains
longitudinal records with participant codes, ages, gender, treatment groups,
assessment sequences, and ADAS-Cog measurements. Public sharing authorization
must be confirmed before it is added to this repository.

For local analysis, place the workbook here as
`rTMS participants pre-post info.xlsx`, or set `RTMS_DATA_FILE` to its actual path.

Required sheet: `weston_export-2`.

Columns in the supplied workbook:

- `Participant`
- `Participant Treatment Group`
- `Participant Age`
- `Participant Gender`
- `Sequence`
- `ADAS-Cog Total Score`
- `ADAS-Cog No Subjective Total Score`
- `ADAS-Cog No Subjective No RTI Total Score`
- `ADAS-Cog-Recog Total Score`
- `ADAS-Cog Recall`
- `ADAS-Cog Naming`
- `ADAS-Cog Commands`
- `ADAS-Cog Const. Praxis`
- `ADAS-Cog Idea. Praxis`
- `ADAS-Cog Orientation`
- `ADAS-Cog Word Recognition`
- `ADAS-Cog Language`
- `ADAS-Cog Comprehension`
- `ADAS-Cog Word Finding`
- `ADAS-Cog RTI`
